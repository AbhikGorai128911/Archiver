# Archiver
a small cli program (mainly designed  for debian proot distro termux) to get off of digital streaming and download media (mainly off of Youtube and Spotify for now)

#Features 

1. download any video/playlist off Youtube in multiple quality

2.download any song/music playlist off Youtube/Youtube Music

3.download any song/music playlist off Spotify

#More about the project 

this is a vibe cooded project. this project works have been made while using chatgpt, gemini, and perplexity. this program offers a simple way to download video and music from yt and yt music using yt-dlp and songs from Spotify using soptdl. Thank You - developer
